# Scope Rush (Runners vs. Snipers)

Online-Multiplayer-Spiel für das iPhone (Hochformat): Läufer rennen einen Parkour hinauf zum Turm, Sniper versuchen sie aufzuhalten, dann werden die Rollen getauscht. 1v1-Duelle und Party-Modus mit Freunden. Läuft komplett kostenlos auf GitHub Pages und Cloudflare Workers.

- **Spielen:** https://m4tt3s-209.github.io/runners-vs-snipers/
- **Plan & Architektur:** [PLAN.md](PLAN.md)
- **Einrichtung (GitHub + Cloudflare):** [docs/SETUP.md](docs/SETUP.md)
- **Entwickeln:** [CLAUDE.md](CLAUDE.md) (Befehle und Konventionen)

Eigene Grafik und Sounds, prozedural erzeugt. Keine Werbung, keine Käufe.
